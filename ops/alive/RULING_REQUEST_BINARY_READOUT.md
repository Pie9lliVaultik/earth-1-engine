# RULING REQUEST — binary readout semantics (external review M07a)

Registered readout: P(YES) = d_NO / (d_YES + d_NO), where d_X is the
force-distance of the X-consequence branch from the null branch.

## The critique, verified

The mapping is DIRECTION-BLIND: an outcome whose modelled consequence is
LARGER is assigned a SMALLER probability by construction. The reviewer's
counterexample is a disruptive but likely event. Our verification
confirmed the formula and noted the structural consequence: both frozen
under-calls on resolved-YES events (SVB 0.302, Sri Lanka 0.399) are
partially explained by the readout's shape, not only by missing physics
channels — a big consequence pushes d_YES up and p down.

## What the current readout has going for it

It is registered, deterministic, reproducible to seven decimals, and its
misses are on the record under sealed protocol. Every committed forecast
used it. Changing it re-opens answer semantics for every question class.

## Options for ruling

A. KEEP, relabel. Keep the formula; stop calling the output a
   probability in the API (rename to consistency_score); event
   probabilities withheld until a calibrated mapping exists. Cost: the
   forecast product loses its p until B/C. Cheapest, most honest.
B. CALIBRATE a monotone map on top. Fit p = g(d_YES, d_NO) on resolved
   events only (n is small today: single digits). Keeps the substrate
   signal, earns the word probability empirically. Needs the event
   battery re-run and more resolutions; prospective register feeds it.
C. REDESIGN the readout (e.g. counted agent-response fractions instead
   of distance ratios, as the reviewer suggests for reaction_share).
   Largest change; touches registered semantics of every class; would be
   its own named cycle with frozen-forecast revalidation from scratch.

## Recommendation

A now (one API relabel, no physics), B as the registered path once the
prospective register accumulates resolutions, C only if B fails. Under
rule "one named change per cycle," A is apparatus, B is a cycle, C is a
programme.

Founder decision recorded here when given. Until then the formula stands
as registered and the paper continues to report its outputs as
model probabilities with the under-call caveat on the record.
