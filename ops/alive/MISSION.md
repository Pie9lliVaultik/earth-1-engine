## The Experience Loop (production-grade, dev-exercised first)
Every forecast = an immutable experience candidate: forecast
timestamp; observation cutoff; world/state hash; genesis version;
theta posterior/version; forcing version; prediction distribution;
uncertainty; resolution criterion; resolution deadline/source.
On resolution: score → diagnose which identifiable components the
evidence supports → update ONLY those → retain posterior uncertainty →
record the exact diff → next model version → test whether subsequent
forecasts improve. Every transition replayable: M_t + E_t → M_{t+1}.
Learning is inference over x_t, θ, u_t, H — do not force every error
into θ. Safety invariant: a parameter may only become confident when
evidence supports that confidence.
Then rolling-origin real-data development: D≤t → forecast_{t+1} →
reveal → learn → forecast_{t+2}, on TRAIN/DEV streams chosen for
resolution frequency, objectivity, coverage, mechanism relevance,
clear observation operators — where Earth-1 learns FASTEST.
